# hermes-superpowers-plugin

> **Status: Reference copy / local experiment. Not portfolio work and not claimed as an original project.**

This repository was used while experimenting with bringing the [`obra/superpowers`](https://github.com/obra/superpowers) methodology into a Hermes environment. Most of the skill material originates upstream, and related community adaptations also informed the experiment.

The repository is not offered as a finished product, supported plugin, or example of original client work. The included upstream license and attribution files should remain with any copy of the material.

It remains public temporarily while the GitHub account is being cleaned up. The intended disposition is private visibility or deletion after the repository history is reviewed.
